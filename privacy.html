プライバシーポリシー

最終更新日：2026年10月14日

sns-autopost（以下「本ツール」）は、運営者本人が所有する YouTube チャンネルおよび Instagram アカウントに、運営者が制作した動画を投稿するためだけに使われる個人用ツールです。

取得する情報

本ツールは、Google（YouTube Data API）および Meta（Instagram API）の認可により発行されるアクセストークンのみを使用します。使用する権限は、動画のアップロードと投稿に必要なもの（YouTube の youtube.upload など）に限ります。

情報の利用目的

取得したトークンは、運営者本人のチャンネル・アカウントへの動画のアップロード、タイトル・説明文の設定、公開日時の設定にのみ使用します。視聴者やほかのユーザーの個人情報は取得しません。

保存と第三者提供

トークンは暗号化された非公開の保管場所（GitHub Secrets）にのみ保存し、第三者に提供・販売することはありません。

Google API Services の利用について

本ツールが Google API から受け取った情報の利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

運営者は、Google アカウントの権限設定からいつでも本ツールへのアクセスを取り消せます。

Privacy Policy

sns-autopost is a personal tool used solely by its operator to upload videos they produced to YouTube channels and Instagram accounts they own. It only uses OAuth access tokens issued by Google (YouTube Data API) and Meta (Instagram API), with the minimum scopes needed to upload videos (e.g. youtube.upload). Tokens are used only to upload videos and set their titles, descriptions and publish times on the operator's own channels. No personal data of viewers or other users is collected. Tokens are stored only in an encrypted private store (GitHub Secrets) and are never sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
